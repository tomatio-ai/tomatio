# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue or pull request for them.

1. **Preferred:** use GitHub's private reporting. On this repository, open the **Security** tab and choose **Report a vulnerability**.
2. **Or by email:** write to **security@tomatio.ai**.

Include what you can of:

- the TomaTío version, and your WordPress and PHP versions;
- what an attacker can do and what they need first (for example a signed-in agent, a curator account, or nothing at all);
- steps or a proof of concept that shows the problem.

We confirm we have your report, keep you informed while we work on it, and credit you in the release notes when the fix ships, unless you prefer not to be named. Please give us a reasonable time to release a fix before you publish details.

## Supported versions

Security fixes go into the latest release. TomaTío updates itself from the Releases page (or from WordPress.org once it is listed there), so keep automatic updates on or update when a new version appears.
